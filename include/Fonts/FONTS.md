# Fonts / Schriften

All display fonts in this folder are free fonts converted to Adafruit-GFX headers:

| Header | Font | Licence |
|---|---|---|
| `ArchivoNB<n>pt7b.h` | Archivo Narrow Bold (Omnibus-Type) | SIL Open Font License 1.1 – `OFL-ArchivoNarrow.txt` |
| `OCRA<n>pt7b.h` | OCR-A (Matthew Skala / Tor Lillqvist / Richard B. Wales) | Public Domain – `LICENSE-OCRA.txt` |

The number `<n>` names the size slot of the layout. The glyphs are scaled so that the digits have
exactly the pixel height and width the layout was designed for, so positions stay unchanged.

---

Alle Display-Schriften in diesem Ordner sind freie Schriften, umgewandelt in Adafruit-GFX-Header
(Tabelle oben). Die Zahl `<n>` ist die Größenstufe des Layouts; die Ziffern sind pixelgenau so hoch
und breit wie vorgesehen, damit alle Positionen gleich bleiben.
